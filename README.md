# _81_

The official interpreter for [_81_](https://esolangs.org/wiki/81), the esolang by [waffelz](https://github.com/waffelz0/). The wiki page covers the language itself.

## Install

Install the interpreter with cargo:

```sh
cargo install eighty-one
```

## Usage

Run a program from a file:

```sh
81 program.81
```

Or run code given directly on the command line:

```sh
81 -c $'OUT [|]\nOUT [1O]'
```
